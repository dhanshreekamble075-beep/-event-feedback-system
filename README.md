# Event Feedback System (Flask Web Application)

A web-based feedback application developed using Python Flask.  
This project allows users to submit feedback for an event and shows a success confirmation page after submission.

---

## 📌 Project Description
The Event Feedback System demonstrates how real-world websites collect and process user input using backend logic.

It uses Flask routing, templates and POST request handling to process feedback form data.

---

## 🛠 Tech Stack
- Python
- Flask
- HTML5
- CSS3

---

## ✨ Features
- Home page
- Feedback form (Name, Email, Message)
- Form submission handling
- Success confirmation page
- Clean and simple UI
